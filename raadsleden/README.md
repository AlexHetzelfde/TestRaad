# Referentiefoto's raadsleden

Zet hier één duidelijke, frontale foto per raadslid neer.

- Bestandsnaam (zonder extensie) = de naam zoals die in de resultaten
  moet verschijnen. Underscores worden spaties: `Jan_Jansen.jpg` → "Jan Jansen".
- Ondersteund: `.jpg`, `.jpeg`, `.png`.
- Eén gezicht per foto is genoeg; staan er meerdere gezichten op, dan
  wordt het grootste gezicht in de foto gebruikt.
- Na het toevoegen/wijzigen van foto's: `python scripts/enroll_faces.py`
  draaien (of gewoon committen — de workflow doet dit automatisch bij
  elke run als deze map niet leeg is).
